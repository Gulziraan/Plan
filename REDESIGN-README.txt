THE WORTHY ARCHIVE — FINAL EDITORIAL REDESIGN

Рабочая база: HASAN-HEAD-SWAY-FIX.zip

Что изменено:
- Добавлена общая визуальная система editorial-system.css, подключённая после основных таблиц стилей обеих глав.
- Согласованы базовые цвета: молочный фон, бордовый, мягкий голубой и приглушённое золото.
- Унифицированы роли шрифтов: Oswald для выразительных заголовков, Manrope для интерфейсных подписей, Cormorant Garamond для длинного эмоционального текста.
- Исправлена глобальная ширина body: страницы больше не ограничиваются узкой колонкой текста; добавлена общая адаптивная ширина сцен.
- Уточнены композиции обложки, профиля, блока качеств, экрана MY SUPERHERO, раздела пяти чувств, загадок, финального письма и фотогалереи.
- Загадки оставлены без декоративных белых карточных фонов.
- Добавлены единые состояния фокуса для клавиатурной навигации и правила для мобильной ширины.

Что намеренно НЕ менялось:
- JavaScript-файлы и логика взаимодействия.
- Механика удержания и поднятия Мьёльнира.
- Тайминги и обработчики анимаций.
- Логика переходов, доступ между главами и localStorage.
- Тексты, загадки, ответы, шифр, фотографии и аудиофайлы.
- URL страниц и структура папок.

Проверки:
- JavaScript: node --check для всех основных скриптов — успешно.
- CSS: разбор всех таблиц стилей — ошибок синтаксиса нет.
- Ссылки на локальные ресурсы из HTML — отсутствующих файлов не обнаружено.
- JavaScript-файлы побайтно совпадают с исходным архивом.
- ZIP integrity — проверена.
- Полный визуальный прогон в браузере в среде сборки заблокирован политикой запуска локальных страниц; поэтому визуальную проверку на реальном ноутбуке/планшете/телефоне необходимо выполнить после публикации.

Публикация:
Загрузите всё содержимое папки Plan-main в корень текущего GitHub Pages сайта, сохранив assets/ и все файлы рядом с index.html.
