# HASAN — глава 24

Сайт работает на чистых HTML, CSS и JavaScript. Сборка и дополнительные библиотеки не нужны.

## Запуск

Открой `index.html` в современном браузере. Все файлы проекта должны оставаться в одной папке.

## Последовательность истории

1. Начальный экран.
2. «Что делает тебя тобой».
3. Вводная глава «Это не про суперсилу».
4. «Пять чувств» — загадки, получение букв и сохранение прогресса.
5. Финальный шифр. После правильного ответа открывается личное письмо.
6. Галерея «Особенные моменты, которые я очень люблю» — ниже письма, на той же странице с обычной прокруткой.

Старые экраны профиля, Мьёльнира и карусели о любви сохранены в исходниках, но исключены из нового маршрута. Разделы «Твоя планка» и «Без фильтров» не добавлены.

## Личное письмо

Открой `content.js` и заполни объект `personalLetter`:

```js
personalLetter: {
  salutation: "Мой любимый,",
  body: "Первый абзац.\n\nВторой абзац.",
  signature: "Всегда твоя ♡"
}
```

Пустое поле `body` намеренно показывает аккуратную подсказку вместо выдуманного письма. Абзацы разделяются пустой строкой.

## Фотогалерея

Фотографии галереи задаются в массиве `galleryPhotos` файла `content.js`.

Сейчас подключены 7 реальных фотографий из папки `assets`. Чтобы добавить остальные (ориентир — до 20):

1. Положи фото в `Plan-main/assets/`.
2. Добавь в `galleryPhotos` объект с путём и коротким alt-текстом:

```js
{ src: "assets/08.jpg", alt: "Наш момент" }
```

Чтобы удалить фотографию — удали её объект из массива. Чтобы заменить — поменяй `src`. Порядок объектов определяет порядок кадров. Галерея сама адаптирует композицию под десктоп и телефон; оригиналы не растягиваются, изображения вписываются с аккуратным кадрированием.

## Прогресс и материалы

Прогресс пяти загадок и доступ к письму сохраняются в `localStorage` браузера. После обновления страницы, если шифр уже разгадан, кнопка на первом экране ведёт прямо к письму. Кнопка «Начать сначала» сбрасывает прохождение, но не удаляет загруженные пользователем фотографии и аудио.

Фотографии, загруженные через элементы сайта, хранятся в локальном хранилище текущего браузера и устройства. Для постоянного хранения и переноса между устройствами добавляй файлы в `assets` и указывай их в `content.js`.
