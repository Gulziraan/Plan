# HASAN — глава 24

Сайт работает на чистых HTML, CSS и JavaScript. Сборка и дополнительные библиотеки не нужны.

## Запуск

Открой `index.html` в современном браузере. Все файлы проекта должны оставаться в одной папке.

## Последовательность истории

1. Кинематографичное вступление.
2. Профиль Хасана и характеристики.
3. Интерактивная сцена Мьёльнира.
4. «Что делает тебя тобой».
5. «За что я тебя люблю» — карусель из шести причин.
6. Вводная глава к пяти чувствам.
7. «Пять чувств» — пять заданий, шифры, получение букв и сохранение прогресса.
8. Финальный шифр «ВЕЧНО», личное письмо и фотогалерея.

Между главами работает отдельная система коротких кинематографичных переходов. Она отключается при `prefers-reduced-motion`.

## Визуальная система

Проект использует HTML, CSS и JavaScript без тяжёлых библиотек. Визуальная режиссура построена на разных атмосферных сценах, металлическом освещении Мьёльнира, editorial-композициях, бумажном оформлении письма и индивидуальной атмосфере пяти чувств.

## Материалы, требующие добавления

В исходном архиве отсутствуют три аудиофайла, на которые ссылается `content.js`:

- `assets/audio/hasan-first-voice.mp3`
- `assets/audio/my-first-voice.mp3`
- `assets/audio/our-song.mp3`

Плееры сохраняют предусмотренное состояние «Аудиозапись скоро появится» до добавления оригинальных файлов. Также в архиве нет `assets/m3.jpg`, а `assets/4.jpg` содержит только 2 байта и не является корректным изображением. Эти исходные материалы не подменялись случайными фотографиями.

## Личное письмо

Открой `content.js` и заполни объект `personalLetter`:

```js
personalLetter: {
  salutation: "Мой любимый,",
  body: "Первый абзац.\n\nВторой абзац.",
  signature: "Всегда твоя ♡"
}
```

Пустое поле `body` намеренно показывает аккуратную подсказку вместо выдуманного письма. Абзацы разделяются пустой строкой.

## Фотогалерея

Фотографии галереи задаются в массиве `galleryPhotos` файла `content.js`.

Сейчас подключены 7 реальных фотографий из папки `assets`. Чтобы добавить остальные (ориентир — до 20):

1. Положи фото в `Plan-main/assets/`.
2. Добавь в `galleryPhotos` объект с путём и коротким alt-текстом:

```js
{ src: "assets/08.jpg", alt: "Наш момент" }
```

Чтобы удалить фотографию — удали её объект из массива. Чтобы заменить — поменяй `src`. Порядок объектов определяет порядок кадров. Галерея сама адаптирует композицию под десктоп и телефон; оригиналы не растягиваются, изображения вписываются с аккуратным кадрированием.

## Прогресс и материалы

Прогресс пяти загадок и доступ к письму сохраняются в `localStorage` браузера. После обновления страницы, если шифр уже разгадан, кнопка на первом экране ведёт прямо к письму. Кнопка «Начать сначала» сбрасывает прохождение, но не удаляет загруженные пользователем фотографии и аудио.

Фотографии, загруженные через элементы сайта, хранятся в локальном хранилище текущего браузера и устройства. Для постоянного хранения и переноса между устройствами добавляй файлы в `assets` и указывай их в `content.js`.

## THE WORTHY ARCHIVE — пространственная версия

Главная точка входа после вступления теперь ведёт в центральный зал THE WORTHY ARCHIVE. Из него доступны отдельные помещения: личное досье, Мьёльнир, качества Хасана, причины любви, фотогалерея и пять чувств. Последняя комната остаётся закрытой до выполнения существующего финального условия.

### 3D-сцены

Файл `world3d.js` создаёт процедурную архитектуру центрального зала и отдельную геометрическую модель Мьёльнира средствами Three.js. Three.js загружается как ES-модуль с jsDelivr CDN; при недоступности WebGL или CDN остаётся рабочая HTML/CSS-версия интерфейса. На телефонах автоматически снижается плотность частиц, pixel ratio и качество теней. Учитывается `prefers-reduced-motion`.

Для локального запуска используй локальный HTTP-сервер (например, `python -m http.server`), поскольку браузеры могут блокировать ES-модули при открытии `index.html` напрямую через `file://`.

Старые HTML-секции, `content.js`, механика загадок и существующие ключи `localStorage` сохранены; новые двери лишь добавляют пространственную навигацию и не сбрасывают прохождение.
