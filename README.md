# Хасан — глава 24

Обновлённая версия существующего сайта. Проект остаётся на чистых HTML, CSS и JavaScript — сборка и дополнительные библиотеки не нужны.

## Запуск

Открой `index.html` в современном браузере. Все файлы проекта должны оставаться в одной папке.

## Что изменено

- Интерактив с Мьёльниром вынесен из профиля в отдельную кинематографичную главу.
- Для поднятия молота можно удерживать его или коснуться три раза.
- После победы открывается отдельное личное послание и возможность повторить сцену.
- Существующие профиль, глава о качествах, пять чувств, загрузка личных фото/аудио и финальное письмо сохранены.
- В проекте используется возраст 24 года.
- Анимации учитывают системную настройку `prefers-reduced-motion`.

## Личные материалы

Фотографии и аудио можно загрузить через элементы сайта. Они сохраняются в локальном хранилище текущего браузера и устройства. Чтобы перенести сайт на другой компьютер, учитывай, что эти загруженные материалы автоматически в архив не попадают.


Дополнительно восстановлена отдельная глава «За что я тебя люблю»: шесть перелистываемых причин, переворот центрального кадра, свайпы на телефоне и загрузка фотографий в каждый кадр.
- Глава «За что я тебя люблю» полностью оформлена в общей тёмной бордово-золотой стилистике сайта: крупный центральный кадр, две боковые карточки, плавная глубина и кинематографический переворот.
- Для каждой причины можно отдельно загрузить фотографию; изображения сохраняются в браузере. Содержание и порядок карточек редактируются в массиве `loveReasons` файла `content.js`; можно добавлять любое количество элементов, а также необязательное поле `caption`.
- Карусель поддерживает стрелки, свайпы и клавиши ← / →.


## Постоянное хранение фотографий в папке сайта

Для главы «За что я тебя люблю» создана папка `assets/love/`. Помести в неё фотографии `01.jpg` … `06.jpg`. Пути к ним уже прописаны в `content.js` в массиве `loveReasons`. Если используешь другие имена или форматы, измени поле `image` у нужной карточки, например `image: "assets/love/hasan.webp"`.

Чтобы добавить карточку, добавь новый объект в `loveReasons` и положи её фотографию в `assets/love/`. Порядок объектов определяет порядок карточек. Поле `caption` необязательно. Не переименовывай и не перемещай `assets/love/`, если не обновляешь пути в `content.js`.

**Важно:** браузер не может автоматически записать выбранный через кнопку файл в папку проекта. Кнопка загрузки оставлена как быстрый вариант и сохраняет фото только в текущем браузере. Для надёжного переноса сайта на другое устройство копируй фотографии вручную в `assets/love/` вместе со всей папкой сайта.
