# Hasan — One Page Experience

Одностраничная версия сайта: все разделы расположены последовательно на одной вертикальной странице. Следующий раздел открывается только после нажатия соответствующей кнопки; ранее открытые разделы остаются доступными выше при прокрутке.

## Запуск

Откройте папку проекта через локальный сервер:

```bash
python -m http.server 8000
```

Перейдите на `http://localhost:8000`.

## Последовательность

1. Приветствие
2. Профиль Хасана
3. Мьёльнир
4. «Что делает тебя тобой»
5. Вводный раздел к пяти чувствам
6. Пять интерактивных загадок
7. Финальное письмо после правильного кода

Удалены отдельная галерея и раздел «За что я тебя люблю». Фотографии, используемые внутри заданий, не удалены.

## Прогресс

Прогресс загадок хранится в localStorage. Кнопка «Начать сначала» очищает прохождение. У открытых разделов нет автоматического закрытия или перехода.

## Примечание

Для загрузки Google Fonts нужен интернет. Письмо в исходном `content.js` оставлено пустым, как и в исходных материалах — личный текст не придумывался.
