# Хасан — глава 24

Обновлённая версия существующего сайта. Проект остаётся на чистых HTML, CSS и JavaScript — сборка и дополнительные библиотеки не нужны.

## Запуск

Открой `index.html` в современном браузере. Все файлы проекта должны оставаться в одной папке.

## Что изменено

- Интерактив с Мьёльниром вынесен из профиля в отдельную кинематографичную главу.
- Для поднятия молота можно удерживать его или коснуться три раза.
- После победы открывается отдельное личное послание и возможность повторить сцену.
- Существующие профиль, глава о качествах, пять чувств, загрузка личных фото/аудио и финальное письмо сохранены.
- В проекте используется возраст 24 года.
- Анимации учитывают системную настройку `prefers-reduced-motion`.

## Личные материалы

Фотографии и аудио можно загрузить через элементы сайта. Они сохраняются в локальном хранилище текущего браузера и устройства. Чтобы перенести сайт на другой компьютер, учитывай, что эти загруженные материалы автоматически в архив не попадают.
