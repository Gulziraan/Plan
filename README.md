# HASAN — THE MAIN CHARACTER

Новая самостоятельная версия проекта в формате интерактивного кинематографичного повествования.

## Запуск

Откройте папку проекта через локальный HTTP-сервер (ES-модуль Three.js загружается из CDN):

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Структура

- `index.html` — новая последовательность сцен и интерфейс.
- `styles.css` — адаптивная визуальная система.
- `app.js` — переходы, интерактивность, 3D-модели, загадки и сохранение прогресса.
- `content.js` — личные тексты, фотографии, качества и данные пяти чувств.
- `assets/` — исходные фотографии проекта.

## Сцены

1. Opening Credits
2. The Hero — интерактивный 3D-Мьёльнир
3. Character Study
4. The Memories
5. Five Senses
6. Final Scene

## Важные примечания по исходным материалам

- Существующие фотографии перенесены из исходной папки проекта; изображения не заменялись генерацией или стоковыми материалами.
- В игре «Найди три отличия» сохранены исходные координаты интерактивных областей: 39.2% / 40.9%, 84.1% / 3.6%, 4.4% / 57.5%.
- Сохранены загадки Морзе и Брайля, ответы, буквы Ч–О–В–Е–Н и финальный код ВЕЧНО.
- Прогресс сохраняется в localStorage. Переходы между сценами выполняются только по действию пользователя.
- В исходном `content.js` личное письмо было пустым. Текст письма намеренно не придумывался: при добавлении исходного текста он отобразится в финальной сцене.
- В исходном проекте отсутствуют три аудиофайла, указанные в старом конфиге; новые аудиозаписи не подставлялись.
- `assets/4.jpg` повреждён (2 байта), `assets/m3.jpg` отсутствует; они не используются как изображения. Остальные исходные файлы сохранены в `assets/`.
- Three.js и GSAP загружаются с CDN, поэтому для полной 3D-анимации требуется интернет-соединение. В сцене Мьёльнира есть drag-вращение, колесо/щипок для zoom и звуковой акцент, синтезируемый по нажатию; сигнал Морзе можно прослушать.

## Управление

- Навигация снизу — предыдущая/следующая сцена.
- `REPLAY` — повторный просмотр/сброс текущего эпизода.
- `SKIP MOTION` — пропуск анимации перехода.
- В сцене Мьёльнира — перетаскивание для вращения, колесо мыши для приближения.
- На телефоне — свайпы в редакционных последовательностях и touch-управление.
